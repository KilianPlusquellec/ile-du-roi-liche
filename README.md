# L'Île du Roi-Liche

Un jeu de survie et d'aventure en 3D : récolte, construis ton camp, choisis ta classe
(Guerrier, Mage ou Druide), explore la Vallée verte, la Forêt sombre et les Pics gelés…
et vaincs le Roi-Liche.

## Jouer

1. Télécharge le launcher : **[IleDuRoiLiche-Launcher-Setup.exe](https://github.com/KilianPlusquellec/ile-du-roi-liche/releases/download/launcher/IleDuRoiLiche-Launcher-Setup.exe)** (Windows 10 / 11).
2. Lance-le. Windows peut afficher « Windows a protégé votre ordinateur » : clique sur
   **Informations complémentaires**, puis **Exécuter quand même**.
3. Le launcher installe le jeu, puis le tient à jour tout seul. Clique sur **Jouer** !

Ta partie est sauvegardée sur ton PC : les mises à jour n'y touchent jamais.

## Ce dépôt

Il ne contient que les versions publiées du jeu (onglet **Releases**) :

- `v1.0`, `v1.1`… : les versions du jeu, signées. Le launcher vérifie la signature avant d'installer.
- `launcher` : l'installeur du launcher, qui se met à jour tout seul.
